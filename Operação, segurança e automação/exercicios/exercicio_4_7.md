# Exercício 4.7: Passos de bebê para GitOps

**Instruções do Exercício:**

> Mova o aplicativo *Log output* para utilizar práticas de GitOps. 
> Configure o ArgoCD para rastrear o repositório da aplicação, de modo que, ao fazer um novo *commit* no repositório (com alterações no código ou nas configurações YAML), o aplicativo seja implantado e atualizado automaticamente no cluster.
