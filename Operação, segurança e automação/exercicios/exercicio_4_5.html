Exercício 4.5: O projeto, passo 22

Aprimore a nossa aplicação de tarefas (todos). O sistema poderia ter um campo 'Concluído' (Done) para tarefas que já foram feitas.
Para implementar isso, o backend deve suportar uma requisição HTTP PUT para a rota /todos/ que marque a tarefa com o ID correspondente como concluída. Atualize também a interface de usuário para permitir essa interação.
