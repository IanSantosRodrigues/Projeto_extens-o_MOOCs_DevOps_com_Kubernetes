# Solução: Exercício 3.2 - Pipeline de publicação

**Guia de Solução:**

### Passo a Passo

1. Configure o pipeline para rodar testes antes do build.
2. Construa a imagem com uma tag baseada no commit.
3. Publique a imagem no registry usando secrets do CI.
4. Atualize o manifesto ou prepare o passo de deploy declarativo.
